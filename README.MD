# Shrink-O-Matic

Shrink-o-Matic is a simple URL Shortener I am building as a way for me to learn to use Flask. 


## Application Dependencies

This is a python based application, The goal here is to only have python based dependencies in the production environment. The Node based dependencies are only used in development.

**Python Dependencies** 
- Flask
- python-dotenv
- watchdog

**Node Dependencies**
- none yet!


Tools i would like to use
